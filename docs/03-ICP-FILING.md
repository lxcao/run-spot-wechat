# ICP 备案完整指南（个人）

> 备案成功后可以绑到 CloudBase / EdgeOne Pages / 任何国内平台，永久去掉测试域名确认页。

**总时长**：7~20 天（个人首次备案）
**费用**：域名注册费（约 50~80 元/年）+ 备案服务费（**腾讯云免费**）

---

## 第一步：买域名（10 分钟）

### 推荐域名

| 域名 | 含义 | 年费 | 推荐度 |
|---|---|---|---|
| `oracle-run.cn` | 甲骨文 + 跑 | ~35 元 | ⭐⭐⭐⭐⭐ |
| `caolingxin.cn` | 个人名 | ~35 元 | ⭐⭐⭐ |
| `oracle-run.com.cn` | 甲骨文 + 跑（com.cn）| ~45 元 | ⭐⭐⭐ |
| `oracle-run.com` | 甲骨文 + 跑（com）| ~75 元 | ⭐⭐（贵，海外解析慢） |
| `caolingxin.com` | 个人名（com） | ~75 元 | ⭐ |

### 域名注册步骤

1. 打开 https://console.cloud.tencent.com/domain
2. 搜索想要的域名（如 `oracle-run.cn`）
3. 选择年费、加入购物车、付款
4. 推荐在**腾讯云**注册（因为要在这备案）
5. 付款完成后 → **域名实名**（下一步）

---

## 第二步：域名实名（1~3 天）

> ⚠️ **必须先实名才能备案**。这一步腾讯云强制要求。

1. 打开 https://console.cloud.tencent.com/domain
2. 找到刚买的域名 → 点 **"未实名"**
3. 选 **"个人"** 模板（需要填身份证信息）
4. 提交后腾讯云审核 1~3 天（一般 1 天）

---

## 第三步：ICP 备案申请（30 分钟填表）

### 备案入口

打开 https://console.cloud.tencent.com/beian

点 **"开始备案"**

### 需要填写的信息

#### 1. 主体信息（个人）
- 姓名：你的身份证姓名
- 证件类型：身份证
- 证件号：身份证号
- 手机号：备案用的手机号（最好用常用手机号）
- 邮箱：备案用的邮箱
- 居住地址：上海 + 你具体住址（区+街道）
- 紧急联系人：可选

#### 2. 网站信息

| 字段 | 怎么填 | 备注 |
|---|---|---|
| 网站名称 | `甲骨文魔都跑团` | 3 字以上，不含敏感词 |
| 网站域名 | `oracle-run.cn` | 不要带 `www.` |
| 服务类型 | `网站` | 不是 `APP` |
| 网站前置审批 | `无` | 跑团不需要特殊审批 |
| 网站语言 | `中文` | |
| 网站内容 | `其他-生活服务` | 跑团服务选这个 |

#### 3. 备案材料

- **身份证正反面**：拍照上传
- **人脸核验**：用腾讯云 App 扫码做人脸识别
- **居住证明**：可有可无，上海可能要求上传居住证或房产证

### 备案流程时间表

```
Day 0  你提交申请 + 人脸核验
Day 1~2  腾讯云初审（一般 1 天通过）
Day 2~3  工信部发短信核验（你手机会收到 12381 发的验证码）
Day 3~15 上海市通信管理局审核（最关键的阶段，7~10 天）
Day 10~20 备案通过，备案号下来
```

---

## 第四步：工信部短信核验（⚠️ 不要错过！）

腾讯云初审通过后，**工信部会发短信到你的备案手机号**（号码 `12381`）：

```
【工业和信息化部】
您的备案信息提交【上海市通信管理局】审核，
验证码：XXXXXX（24小时内有效）
```

**这一步必须在 24 小时内回短信确认**，否则备案会被打回！

---

## 第五步：等待管局审核（5~10 天）

审核期间偶尔会打电话给你确认，**接听电话并如实回答**：
- "是不是本人申请？"
- "网站是做什么的？" → "上海跑团微信群活动通知"
- "网站负责人是谁？" → 你自己

---

## 第六步：备案成功 + 绑 CloudBase（5 分钟）

备案号下来后（一般显示在腾讯云控制台 + 工信部网站），**备案完成**。

接下来绑定到 CloudBase：

1. CloudBase 静态托管控制台 → **域名管理**
2. 点 **添加域名** → 输入 `oracle-run.cn`
3. 按提示到**腾讯云 DNSPod** 添加 CNAME 记录
4. CloudBase 自动签发 HTTPS
5. **5 分钟后访问 `https://oracle-run.cn`**

**永久稳定，无确认页，微信不风控！**

---

## ⚠️ 备案常见被拒原因

| 原因 | 怎么避免 |
|---|---|
| 网站名称不规范 | 用 `甲骨文魔都跑团`，别用 `甲骨文集团`、`上海跑团联盟` 等 |
| 居住地址与身份证不一致 | 用身份证上的地址，或上传居住证 |
| 身份证模糊 | 拍照时确保四角完整、文字清晰 |
| 工信部短信没回 | 设置短信免拦截 / 24 小时内必须回 |
| 网站内容分类错 | 跑团 = `其他-生活服务`，不是 `社交` `论坛` `博客` |
| 一个人多个备案 | 个人名下已经有其他备案，需要注销后重新申请 |
